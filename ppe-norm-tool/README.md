# ppe-norm-tool

Дарханы Төмөрлөгийн Үйлдвэрийн дөрвөн нэгжийн (Гангийн үйлдвэр, Төмөртэй уурхай,
Төмөр толгой уурхай, Төмөр замын өртөө) ажлын хувцас/ХХХ-ийн жилийн норм хэрэглээ,
төсвийн тооцоо, ажилтан тус бүрийн солих хугацааны хяналтад зориулсан
дахин ашиглагдах Python хэрэгсэл.

**Тэргүүлэх зорилт:** 2026.07.20-ны ХАБЭА зөвлөлийн хуралд зориулсан 2027 оны
төсвийн тооцоо (forecast). Солилтын хяналт (replacement) хоёрдугаарт.

## Төслийн бүтэц

```
ppe-norm-tool/
  data/    norm.xlsx, headcount.xlsx, issuance.xlsx (жишээ өгөгдөл)
  src/     forecast.py, replacement.py, main.py
  output/  forecast_report.xlsx, replacement_due.xlsx, mismatch.xlsx (шаардлагатай бол)
  README.md
```

## Суулгах

```
pip install pandas openpyxl
```

## 1. Жилийн норм хэрэглээ ба төсвийн тооцоо (forecast)

```
python src/main.py forecast --reserve 0.1
python src/main.py forecast --reserve 0.15 --site Өртөө
```

- `--reserve` — нөөцийн хувь (жишээ: 0.1 = 10%). Компанийн нийт төсвийн мөрөнд нэмэгдэнэ.
- `--site` — зөвхөн нэг талбайг тусад нь тооцоолох (жишээ: `--site Өртөө`).

**Логик:**

1. `norm.xlsx` × `headcount.xlsx`-ыг талбай + албан_тушаал түлхүүрээр нэгтгэнэ.
   Хоёр талд таарахгүй нэршил гарвал алдаа болгож зогсоохгүй,
   `output/mismatch.xlsx`-д бичээд үргэлжлүүлнэ.
2. Жилийн хэрэгцээ (ширхэг) = (ажилтны_тоо + төлөвлөсөн_нэмэгдэл) × норм_тоо × (12 ÷ хугацаа_сар).
   `элэгдлээр` төрөлд `элэгдэл_дундаж_сар`-ыг хугацаа_сар оронд ашиглана.
   `элэгдэл_дундаж_сар` дутуу бол "тоогоор тооцох боломжгүй" гэж флаглаж, төсвийн
   нийт дүнд оруулахгүй.
3. Жилийн төсөв (₮) = жилийн хэрэгцээ × нэгж_үнэ. `нэгж_үнэ` хоосон бол
   "үнэ дутуу" гэж флаглаж, нийт дүнд оруулахгүй.
4. `output/forecast_report.xlsx`-д гурван түвшний тайлан гарна:
   - **Дэлгэрэнгүй** — нэр төрлөөр мөр бүрчлэн
   - **Талбайгаар нэгтгэл** — талбай тус бүрийн нийт хэрэгцээ/төсөв
   - **Компанийн нийт** — компанийн нийт дүн + нөөцийн мөр
   - (`mismatch.xlsx` хоосон биш үед) **Анхааруулга** хуудас нэмэгдэнэ.

## 2. Ажилтан тус бүрийн солих хугацааны хяналт (replacement)

```
python src/main.py replacement --asof 2026-07-08 --days 30
```

- `--asof` — хяналт хийх огноо (`YYYY-MM-DD`). Өгөгдөөгүй бол өнөөдрийн огноо.
- `--days` — дуусахад үлдсэн хоногийн босго (default: 30).

**Логик:**

1. `issuance.xlsx`-с ажилтан + нэр төрөл тус бүрийн хамгийн сүүлийн олголтыг
   сонгоод, `norm.xlsx`-ийн `хугацаа_сар`-ыг ашиглан дуусах огноог тооцно
   (зөвхөн `тогтмол` төрөлд).
2. `элэгдлээр` төрөлд due-date тооцохгүй, "Үзлэгээр солино" хуудсанд тусад нь
   гаргана.
3. `output/replacement_due.xlsx`-д гурван хуудас гарна:
   - **Хугацаа хэтэрсэн** — талбайгаар бүлэглэсэн, хэтэрсэн хоногтой
   - **`N` хоногт дуусах** — талбайгаар бүлэглэсэн, үлдсэн хоногтой
   - **Үзлэгээр солино** — `элэгдлээр` төрлийн зүйлс
   - (norm.xlsx-с олдоогүй мөр байвал) **Анхааруулга** хуудас нэмэгдэнэ.

## Өгөгдлийн схем

### `data/norm.xlsx` — Норм (single source of truth)

| багана | тайлбар |
|---|---|
| талбай | Гангийн үйлдвэр / Төмөртэй / Төмөр толгой / Өртөө |
| албан_тушаал | ажлын байр / албан тушаал |
| нэр_төрөл | ХХХ-ийн нэр төрөл |
| норм_тоо | нэг олголтод өгөх тоо (ширхэг) |
| хугацаа_төрөл | `тогтмол` эсвэл `элэгдлээр` |
| хугацаа_сар | `тогтмол` төрөлд солих хугацаа (сар); `элэгдлээр` бол хоосон |
| элэгдэл_дундаж_сар | `элэгдлээр` төрөлд төсөв тооцох зорилгоор ашиглах дундаж хугацаа (сар) |
| нэгж_үнэ | нэгжийн үнэ (₮), сүүлийн худалдан авалтын үнээр |

### `data/headcount.xlsx` — Ажилтны тоо

| багана | тайлбар |
|---|---|
| талбай | нэгж |
| албан_тушаал | norm.xlsx-тэй яг таарах нэршил |
| ажилтны_тоо | одоогийн орон тоо |
| төлөвлөсөн_нэмэгдэл | дараа жил нэмэгдэх орон тоо (байхгүй бол 0) |

### `data/issuance.xlsx` — Олголтын бүртгэл

| багана | тайлбар |
|---|---|
| ажилтны_код | дугаар/код |
| овог_нэр | |
| талбай, албан_тушаал | |
| нэр_төрөл | |
| олгосон_огноо | YYYY-MM-DD |
| тоо | |

`data/_make_sample_data.py` нь эдгээр гурван Excel файлын жишээ өгөгдлийг үүсгэсэн
скрипт (шинэ жишээ өгөгдөл хэрэгтэй бол дахин ажиллуулж болно).

## Захын тохиолдлууд

- Дунд жил элссэн ажилтан — эхний олголт хувь тарифтай; forecast-д headcount-ын
  нэмэгдлээр барагцаалж, нарийвчлалыг issuance-аас 2-р шатанд тооцно.
- Гэмтэл/гээгдлийн эрт солилт — норм бол baseline; бодит vs норм зөрүүг 2-р
  шатанд хянана (одоогийн хувилбарт орсонгүй).
- Үнэгүй мөр (нэгж_үнэ хоосон) — тайланд "үнэ дутуу" флагтай гарч, нийт дүнд
  ороогүй болно.

## SharePoint-той холбох

Одоогоор `data/` доторх локал Excel-ийг уншиж байна. Ирээдүйд SharePoint
Excel/Lists-тэй холбоход `src/forecast.py`, `src/replacement.py`-ийн
`pd.read_excel(...)` дуудлагуудыг SharePoint эх сурвалж руу чиглүүлэхэд хангалттай
— үлдсэн логик өөрчлөгдөхгүй.
